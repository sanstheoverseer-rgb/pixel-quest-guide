## Late Game (Extremes) — Krampus, Seer, Tyler
- Big difficulty jump warning
- **Krampus:** Cbow, Necklace of Fangs, Heart, Saber, Kramp Bomb
- **Seer:** Omni (mention how much you hate this weapon), Seer Incan, Seer Crown, Guest Hat, Guest Cape, Guest Gun
- **Tyler:** AWP, Paintball Gun, Paintball Vest, Iron Thorn Rings, Draco Axe, Draco Belt
- **Top sets:** Paintball Set, Crimson Set, Drako Set
- **Build 1:** Crimson Bow + Totem/Flag + Trickster's Vest + Necklace of Fang (Soothing Pendant also excellent) — Trickster's Vest beats pairing with Paintball Vest here
- **Build 2:** Paintball Gun + Totem/Flag + Paintball Vest + Scorching Fist
- **Build 3:** Drako Axe + Totem + Dough Armor + All-Seeing Crown (beats Scorching Fist for this build despite ASC's -30 Dex drawback)
- Niche note: Crimson Heart can work as a quick-swap for burst HP during specific stand-still attack windows, but skip it as a core pick — Hearts are generally hard to use in Extreme fights
- Skip Infernal Ignis — even after its mana-cost buff (50→40) it's still weak, needs 600 [stat] for max crit and only nets ~11% crit increase
- **Best staff build:** Azazel's Penlight + Totem + Lichbound Shroud + Demon Claw, or Azazel's Penlight + Infernal Liber Ignis/Totem + Soot-Choked Cowl + Demon Claw
- Ashen Altar's staff = 2nd best staff overall; its accessory is BiS for staves except for Ouroboros

## Ashen Altar
- **Ashen Altar (Difficulty 8):** no teleport, permadeath, 40 max players, pity caps at 50, 15k chest health. Boss: Demon Idol Azazel. Legendaries: Azazel's Penlight, Infernal Liber Ignis, Soot-Choked Cowl, Demon Claw
- One difficulty tier above Citadel — covered right here, before Corrupted content

## End Game — Corrupted
- Corrupted dungeons: **Azazel, Cbog, Cpirate (Crate), Cruin, Cpalace, Cahi, Cartic**
- Difficulty is genuinely disputed among players for multiple dungeons:
  - Cbog gets called both easiest and hardest depending who you ask
  - Azazel is also disputed — some think it's harder than Cbog/Cruin/Cpirate, others think it's easier than Cbog
- Recommended order: **Azazel → Cbog → Cpirate → Cruin** (similar difficulty, release order since they follow Juan's lore) → **Cpalace → Cahi** → **Cartic** (widely agreed 2nd hardest overall)
- Cbog drops **Lull**, a fan-favorite item — hype it up
- **Bow/Axe BiS gear pool** (general pool, not dungeon-specific pairing):
  - Bedge + Rend + Dough + All Seeing/Abyssal
  - Arma/Ewinter + Paintball Vest + Dba/Abyssal
  - Laev + Styg + Toxin/Dba/Abyssal
  - Plague + Pveil + Cpatch
  - Ice Age + Pveil + Abs0
  - Elder + Lichbound + Abyssal/Demon Claw
  - DBA is strong but genuinely hated to use
  - If not counting Palace: Pveil → Prism Cloak, Abs0 → Abyssal/Coins, Ice Age → Unsealed, Ewinter → Arma
- Paintball Gun ("pbg") is underrated here — Necro/Toxin + Paintball Gun combo works well; can consider swapping AWP+Paintball Gun together, but Scorching Fist isn't great in this tier so pair with a crown-type item instead
- Demon Claw = the standout unique/viable drop from this tier
- **Spells/Totems:** reuse earlier totems/flags, add Sigil/Ashen Flag, Boulder/Avalanche, and Madness
  - Madness isn't actually bugged (rumor debunked) — just note the Age lifesteal heal dropped from 16 → 15 at some point
- Wrap-up: corrupted BiS gear is honestly easy to figure out once you're at this stage
